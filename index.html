Projects

WebNova — Campus Events Platform

Made with: Node.js, Express, MySQL, bcrypt, express-session

Full-stack CRUD platform for campus events where admins create and manage events, students browse and register. 17 REST API endpoints over a 4-table MySQL schema, with bcrypt password hashing and server-side role-based access control. Built as a team project for SOEN 287, then independently hardened (removed hardcoded secrets, fixed schema mismatches) and deployed on Render with Aiven.

Full-stack task manager with user accounts, protected API routes, and full CRUD for tasks organized by category and priority. 9 REST API endpoints, with sessions persisted in MySQL instead of in memory. Deployed on Render with Aiven.
